## Featured project

**[Steam Inventory PnL](https://github.com/KenHuangTW/steam-inventory-pnl)** is a browser extension I built to answer a simple question when looking at a Steam item: what would I actually earn after fees? It uses the purchase cost and quantity I enter to show estimated profit and the break-even sale price directly on Steam. The data stays in the browser.
